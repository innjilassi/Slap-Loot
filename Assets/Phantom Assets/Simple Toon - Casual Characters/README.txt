This package contains a set of 6 cartoon‑style humanoid characters, designed for use in Unity3D projects. 
Each character is optimized for performance, fully rigged, and ready to be animated using third‑party animation libraries such as Mixamo.

The asset is suitable for mobile, desktop, and VR applications.



CONTENTS

6 unique cartoon characters

3 color texture variations per character > 18 total texture variations

Humanoid rig compatible with Unity’s Humanoid Avatar system

5‑finger hand rig for full animation compatibility

Interchangeable textures between Male 02 and Female 02

~8,000 triangles per character (optimized for performance)

No animations included



TECHNICAL SPECIFICATION

Format: FBX

Polygon count: ~8k triangles per character

Materials: URP Lit Shader

Textures: 2048 x 2048 (3 color variations per each character), 1024 x 1024 (hair)

Characters Male 02 and Female 02 share identical UV layouts, allowing texture swapping between them.

Rigging: Humanoid, 5‑finger hands, 2 independent eyes

Compatible with: Unity Humanoid Avatar, Mixamo animations, Third‑party humanoid animation pack



ADDING HAIR, BEARDS AND ACCESSORIES

To replace or customize hair, beards, hats, masks, or any other head‑mounted accessory, make sure to follow this workflow:

Place the accessory at the same coordinates as the character model so it aligns correctly in the scene.

In the character’s hierarchy, locate the "HEAD container" inside the rig.

Move the hair, beard, or accessory GameObject inside the "HEAD container".
This ensures the item follows all head movements, rotations, and animations.

Any head‑related asset must be parented to the HEAD container to behave correctly during gameplay and animation.



NOTES
Animations are not included in this package.

For best results, use Unity’s Humanoid animation retargeting system.

Texture swapping between Male 02 and Female 02 is fully supported.
